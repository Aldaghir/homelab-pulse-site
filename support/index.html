Support

Help when something does not work, and ways to keep Homelab Pulse going.

01 Help

When something does not work

Start with the guides. If they do not answer it, write.

  1. The setup guides

    Installing the agent, reaching your server from anywhere, Telegram, Uptime Kuma and invites, step by step with the app’s own screens.

    All setup guides

  2. Email

    Say what you did and what you saw, with the app’s version from Settings › About and the agent’s from hlpulse-agent version on the server.

    android@aldaghir.com

  3. GitHub Issues

    Bugs and ideas in the open, where others can find the answer too.

    Open an issue

    Issues open with the repository, at the first public release.

  4. A security problem

    Not in a public issue, please. Email the address above with the steps to reproduce it; you hear back within 72 hours.

    How to report it, and what happens next
