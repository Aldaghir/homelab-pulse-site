Download

Homelab Pulse comes in two parts: the app on your Android phone, and a small agent on each server it watches.

01 The app

On your phone

Android 8.0 or later. Two editions share one version number and every fix; only the Google Play edition sells Pro.

What each version changes

  1. Google Play coming soon

    The edition with Pro, an optional one-time purchase. Its link appears here when the app is published.

    What Pro includes

  2. APK from GitHub Releases with the first release

    The community edition, as an APK: free and open source, with every feature of the core and without Pro.

    GitHub Releases

    Downloads open with the first public release, coming soon. Notify me at launch

  3. Check the APK

    The SHA-256 fingerprint of the certificate the APK is signed with is published with the release. Compare it with what apksigner, from the Android SDK build tools, prints for the file you downloaded:

    apksigner verify --print-certs <file.apk>

    Once it is installed, Android accepts an update over it only when the update is signed with the same key.

02 The agent

On each server

Debian, Ubuntu or Raspberry Pi OS, 64-bit (arm64 or amd64), with systemd.

your server

curl -fsSL https://github.com/Aldaghir/homelab-pulse/releases/latest/download/install.sh | sudo sh

This command goes live with the first public release, coming soon. Notify me at launch

The script installs the agent only when the release’s list of checksums carries a valid signature from the project’s release workflow and the downloaded agent matches it. Then it prints a QR code: scan it in the app and your phone is paired.

03 Checking

Check a download yourself

What the install script does for you, by hand.

  1. What a release signs

    Each release carries checksums.txt, the SHA-256 of the agent for arm64 and amd64, its Debian packages, install.sh and the agent’s software bill of materials (CycloneDX). The release workflow signs it with Sigstore, with no long-lived key, so the signature in checksums.txt.sigstore.json names that workflow and the release’s tag.

  2. Check the signature, then the files

    In the folder of your downloads, with cosign installed:

    cosign verify-blob checksums.txt \
  --bundle checksums.txt.sigstore.json \
  --certificate-identity-regexp '^https://github\.com/Aldaghir/homelab-pulse/\.github/workflows/agent-release\.yml@refs/tags/v[0-9]' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
sha256sum -c checksums.txt --ignore-missing

    The APK is not listed in checksums.txt: check it by its certificate, above.
