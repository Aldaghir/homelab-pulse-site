Your home server in your pocket

Homelab Pulse is an Android app that monitors and manages your home server through a tiny agent you install on it: live health, alerts before things break, and safe control from anywhere.

Up and running in three steps

A tiny agent on your server collects metrics, keeps history and sends alerts; the app shows everything and puts you in control.

  1. Install the agent

    One command on Debian, Ubuntu or Raspberry Pi OS.

    curl -fsSL https://github.com/Aldaghir/homelab-pulse/releases/latest/download/install.sh | sudo sh

Frequently asked questions

Which server systems are supported?

64-bit Debian, Ubuntu and Raspberry Pi OS (arm64 or amd64) with systemd. Docker support turns on by itself when Docker is there.

Do I need to open ports on my router?

No. At home the app talks to your server directly; away it goes through Cloudflare Tunnel, protected by Cloudflare Access.

Where is my server's data stored?

On your server. The app talks to the agent directly, and push alerts are end-to-end encrypted so nobody else can read them.

How much does the agent use?

On a Raspberry Pi 5: about 26 MB of memory and under 1% of the CPU on average.

Do alerts work without Google services?

Yes, through Telegram with your own bot; the server sends them directly, even to a phone without Google services.
