Source Code

Homelab Pulse is open core. The app’s core, the agent on your server and the push relay are free software: you may use, study, change and share them. Only Pro, sold in the Google Play edition, is closed.

01 What is open

Each part and its license

Both editions are built from the same code: a fix is written once and reaches both on the same day.

  1. The app’s core GPL-3.0-only

    Everything the app does without Pro: monitoring, containers and services, logs, the terminal, alerts, remote access and invites.

    You may run, study, change and share it. A changed version you share goes with its source, under the same license. The GNU General Public License v3.0

  2. The agent, its API and the push relay Apache-2.0

    What runs on your server, all of it, with every capability for every user. It runs with privileges there, so you can read every line of it.

    You may use, change and ship it, in a closed product too, keeping its license and notices. The Apache License 2.0

  3. Pro closed

    The features Pro opens, and the Google Play edition’s own code that sells it, are not published, and these licenses do not cover them.

  4. The libraries inside the app their own licenses

    Each keeps its own license. The app lists every one with its license’s full text, under Settings › About › Every library and its license.

02 The code

Getting the source code

  1. By email

    To get the source code of the app’s core and of the agent, write with the version shown in Settings › About.

    android@aldaghir.com

03 Building

Build it yourself

From the top folder of the source code.

  1. The agent

    With Go 1.27 or later: its tests, then one static binary, agent/bin/hlpulse-agent.

    cd agent
make test
make build

  2. The app

    With JDK 21 and the Android SDK: the community edition, as a debug APK.

    cd android
./gradlew assembleDebug

    Push notifications need a Firebase project of your own, its google-services.json in android/app. The app builds without it.
